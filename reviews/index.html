HOW IT WORKS

開通步驟（給店家／管理員）

  1. 01 確認 Google 商家檔案（Google Business Profile）已完成驗證，且商家名稱、地址、電話與官網一致。
  2. 02 於 Google Cloud Console 啟用 Places API，取得 API Key，並限制只能用於本站網域。
  3. 03 在後台「評論設定」填入 Place ID 與 API Key，執行一次同步；系統會快取評論內容與更新時間。
  4. 04 檢視同步結果：確認評論數量、平均星等與原始連結正確，再將此頁狀態改為「已發布」。
POLICY

我們的評價原則

  • 只顯示可追溯來源的評論，並標示來源與日期。
  • 不修改評論文字、不選擇性只放好評。
  • 顧客要求移除時，會在下一次更新時下架。

這一頁不會出現示範用的星等或評論數量。只有在取得可追溯來源後，才會顯示真實評分。
